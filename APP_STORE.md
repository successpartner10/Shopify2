## Full description (paste)

Storescope is a standalone helper for Shopify admin. Share the admin tab on a computer, or upload a screenshot on a phone. It matches a local playbook and lists the next taps.

- Opens in a **new tab** so the browser can share the Shopify tab. It is not an embedded admin iframe.
- Screenshots and tab pixels are read on this device. They are not uploaded to a Storescope server.
- We do not request Admin API scopes. We do not log into the shop or change the shop.
- Playbooks cover common payout, shipping, theme, checkout, and Help Center how-tos.
- You can save a how-to you typed. It stays on this device.
- On a phone: screenshot Shopify admin, then upload it from Photos.

Storescope does not click in admin for you. It does not lift a Payments or Risk hold. For store data inside Shopify, use Shopify admin tools.

---

## How it works (paste)

1. Install. Shopify opens Storescope in a new tab.
2. Open Shopify admin in another tab, or take a screenshot on a phone.
3. Share that Shopify tab, or upload the screenshot, or type the banner.
4. Follow the numbered steps. Play this fix can read the current step aloud.
